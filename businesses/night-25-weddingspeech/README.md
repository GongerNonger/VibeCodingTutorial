# Night 25 of 25: WeddingSpeech - Wedding Speech Writer (FINAL NIGHT!)

**The 25 Overnight Businesses challenge is COMPLETE!**

## What It Does

WeddingSpeech helps users create heartfelt, personalized wedding speeches in seconds. Users input details about the couple and their relationship, choose a tone and length, and receive a beautifully structured speech ready to deliver at the big day.

## Revenue Model

$15 per generated speech.

## Features

- **Role-specific openings** - Best man, maid of honor, father/mother of bride, friend, sibling, and more
- **Tone control** - Heartfelt, funny, formal, or casual
- **Length control** - Short (~2 min), medium (~4 min), or long (~6 min)
- **Personalized content** - Weaves in names, memories, and couple qualities throughout
- **Structured sections** - Opening, anecdote, qualities, advice, and toast
- **Copy to clipboard** - One-click copy for easy use
- **Speech history** - Browse and revisit previously generated speeches
- **Regenerate** - Get a fresh version with the same inputs

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Dark theme with pink-500 accents

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Tests

```bash
npx tsx test.ts
```

## Deployment

Deploy to Vercel:

```bash
npx vercel
```

No external APIs or databases required - all speech generation is template-based and runs locally.
