# TestimonialWall - Testimonial Collection & Display

> Night 5 of 25 Overnight Businesses

## What It Does
Create testimonial walls, collect social proof, and display them beautifully. Choose grid, masonry, or carousel layouts. Get an embeddable widget.

## Revenue Model
- **Free**: 1 wall, 10 testimonials
- **Pro**: $24/mo unlimited walls + custom branding

## Tech Stack
- Next.js 16 (App Router), Tailwind CSS 4, TypeScript

## Getting Started
```bash
npm install && npm run dev
```

## How It Works
1. Create a testimonial wall (name + description)
2. Add testimonials: author, role, company, quote, star rating
3. Switch to Preview mode to see your wall rendered
4. Choose layout: grid, masonry, or carousel
5. Copy embed code for your website
