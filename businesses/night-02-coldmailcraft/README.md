# ColdMailCraft - AI Cold Email Writer

> Night 2 of 25 Overnight Businesses

## What It Does
Input your product and target company — get a personalized cold email sequence with multiple follow-up angles. No AI API key needed for the MVP.

## Revenue Model
- **Starter**: $19/mo for 100 emails
- **Pro**: $49/mo unlimited

## Tech Stack
- Next.js 16 (App Router)
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## How It Works
1. Enter your product name and description
2. Enter the target company and person/role
3. Choose tone (professional, casual, direct) and sequence length (1-5)
4. Get a full email sequence with different follow-up angles:
   - **Email 1**: Initial outreach with value proposition
   - **Email 2**: Pain point follow-up
   - **Email 3**: Social proof angle
   - **Email 4**: Value-add (give first approach)
   - **Email 5**: Breakup email (graceful close)
5. Copy individual emails or download the full sequence
