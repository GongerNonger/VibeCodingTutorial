# ChangelogHQ - Product Changelog Generator

> Night 6 of 25 Overnight Businesses

## What It Does
Create and display product changelogs with a timeline UI. Add entries with version, type (feature/fix/improvement/breaking), and details. Export as Markdown.

## Revenue Model
- **Free**: 1 changelog, 20 entries
- **Pro**: $19/mo unlimited + custom domain

## Tech Stack
- Next.js 16 (App Router), Tailwind CSS 4, TypeScript

## Getting Started
```bash
npm install && npm run dev
```

## How It Works
1. Add changelog entries: version, title, date, type, description, details
2. Entries appear in a timeline with colored type badges
3. Filter by type (features, fixes, improvements, breaking changes)
4. Pre-seeded with 3 example entries
5. Export full changelog as CHANGELOG.md
