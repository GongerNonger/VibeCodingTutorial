# SEOBrief - AI Content Brief Generator

> Night 3 of 25 Overnight Businesses

## What It Does
Enter a target keyword and search intent — get a comprehensive SEO content brief with a structured outline, questions to answer, related keywords, competitor gap analysis, and writing guidelines. Export as Markdown.

## Revenue Model
- **Free**: 3 briefs/day
- **Pro**: $29/mo unlimited briefs + team sharing

## Tech Stack
- Next.js 16 (App Router)
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## How It Works
1. Enter your target keyword (e.g. "project management software")
2. Select search intent: Informational, Commercial, Transactional, or Navigational
3. Set target word count (500-5000) and audience
4. Get a full content brief with:
   - **Smart Outline**: Intent-aware sections with word estimates and writing notes
   - **Keyword Intelligence**: Related keywords, LSI terms, questions to answer
   - **Competitor Analysis**: Competitor angles and gaps to exploit
   - **Guidelines**: Content dos and don'ts for writers
5. Export as Markdown and hand off to your content team
