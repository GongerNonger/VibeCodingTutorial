# PricingPage - SaaS Pricing Page Generator

> Night 4 of 25 Overnight Businesses

## What It Does
Configure your product tiers and get a beautiful, responsive pricing page as standalone HTML. Choose between minimal, cards, or gradient styles.

## Revenue Model
- **Free**: 3 pages/day
- **Pro**: $19/mo unlimited + custom branding

## Tech Stack
- Next.js 16 (App Router), Tailwind CSS 4, TypeScript

## Getting Started
```bash
npm install && npm run dev
```

## How It Works
1. Enter product name and configure up to 4 pricing tiers
2. Each tier: name, price, billing period, features list, highlighted toggle
3. Choose style (minimal/cards/gradient) and accent color
4. Generate and preview the pricing page
5. Copy HTML or download as standalone .html file
