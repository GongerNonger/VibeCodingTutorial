# ReviewReply - Google Review Response Writer

**Night 17 of 25** | Overnight Business Factory

## What It Does

Business owners paste customer reviews and get professional, on-brand response suggestions with tone controls. Supports Google, Yelp, TripAdvisor, and Facebook reviews.

## Revenue Model

$19/mo per business location

## Features

- **Review Input** - Paste reviews with star ratings, platform, and business name
- **Sentiment Analysis** - Automatic detection of positive, neutral, and negative reviews
- **Tone Controls** - Professional, friendly, empathetic, and apologetic response styles
- **Response Generation** - Contextual responses that address praise, complaints, and mixed feedback
- **Copy & Regenerate** - One-click copy and easy tone switching
- **Review History** - Browse and re-respond to past reviews

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- In-memory data store (no external APIs)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Testing

```bash
npx tsx test.ts
```

## Deployment

```bash
npm run build
npm start
```

Deploy to Vercel, Railway, or any Node.js host.
