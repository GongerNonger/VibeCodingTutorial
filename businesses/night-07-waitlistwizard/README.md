# WaitlistWizard - Launch Waitlist Page Builder

> Night 7 of 25 Overnight Businesses

## What It Does
Build beautiful waitlist landing pages for your product launch. Configure product info, features, style — get a standalone HTML page with email collection.

## Revenue Model
- **Free**: 1 page
- **Pro**: $19/mo unlimited + custom domains + analytics

## Tech Stack
- Next.js 16 (App Router), Tailwind CSS 4, TypeScript

## Getting Started
```bash
npm install && npm run dev
```

## How It Works
1. Enter product name, tagline, description
2. Add features (up to 6)
3. Choose style (minimal/bold/gradient) and CTA text
4. Add optional social proof badge
5. Generate and preview the waitlist page
6. Download as standalone .html or copy the HTML
